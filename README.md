# University Algorithms Portfolio

A curated collection of C programming practicals completed during university studies, focused on algorithms and data structures.

## Projects

| Project | Description |
|---|---|
| [Quick Sort](quicksort/) | Recursive partition-based sorting |
| [Dual-Pivot Quick Sort](dual-pivot-quicksort/) | Sorting with two pivots |
| [Radix Sort](radix-sort/) | Bit-oriented integer sorting |
| [Quickselect](quickselect/) | Finding a k-th order statistic |
| [Heapselect](heapselect/) | Selection using a binary heap |
| [Running Median](running-median/) | Updating a median using two heaps |
| [Counting Sort](counting-sort/) | Sorting with a frequency array |
| [Lexicographic Permutations](lexicographic-permutations/) | Computing a k-th permutation |

## Language

- C

## Purpose

This repository documents university coursework and practical experience with algorithms, recursion, sorting, selection, combinatorics, and heap-based data structures.

## Build

Each project directory contains its own source files and README with a GCC build command. Input formats are specific to the corresponding university exercise.

## Disclaimer

These are educational exercises, not production-ready libraries. Review and test implementations before relying on them in other projects.
