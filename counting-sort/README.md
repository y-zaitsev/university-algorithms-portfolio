# Counting Sort

A counting-based sorting algorithm for integer values in a bounded range.

## Topics

counting sort, frequency array, integer sorting

## Build

Compile the source files with a C compiler such as GCC:

```bash
gcc -std=c11 -Wall -Wextra main.c utils.c -o app
```

Run the program:

```bash
./app
```

On Windows, run `app.exe` instead. The program reads input from standard input; check the original university task for the expected input format.

## Notes

This is an educational university practical. The implementation and output format follow the original exercise. Testing and polishing may be needed before treating it as a production-ready implementation.
